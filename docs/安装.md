# 让别人装：三种方式

## 方式一：npm（最省事，推荐卖给普通用户）

发布一次之后，别人只需要在自己的 DSH profile 里加两行：

```json
{
  "dependencies": { "dsh-ear": "latest" },
  "dsh": { "profile": { "bundles": ["...原有的...", "dsh-ear"] } }
}
```

然后重启 DSH，敲 `/ear`。

发布命令（你有 npm 账号就行）：

```bash
cd dsh-ear
npm login
npm publish --access public
```

> 包名 `dsh-ear` 如果被占用，可以改成带前缀的，例如 `@你的名字/dsh-ear`，记得同步改 `package.json` 里的 `name`。

## 方式二：GitHub（免费，适合先试水）

1. 在 GitHub 新建一个空仓库；
2. 把 `dsh-ear` 这个目录推上去；
3. 别人在 profile 里写：

```json
{
  "dependencies": { "dsh-ear": "github:你的用户名/dsh-ear" },
  "dsh": { "profile": { "bundles": ["...原有的...", "dsh-ear"] } }
}
```

也可以把打好的 `dsh-ear-0.1.0.zip` 传到 GitHub 的 Releases 里，当附件下载。

## 方式三：zip + 安装脚本（给不想改配置的人）

1. 下载 `dsh-ear-0.1.0.zip`，解压到任意目录（例如 `C:\Aurabot\dsh-ear`）；
2. 右键「使用 PowerShell 运行」：

```powershell
powershell -ExecutionPolicy Bypass -File C:\Aurabot\dsh-ear\scripts\install.ps1
```

脚本会：备份 profile 的 `package.json`、加上依赖和 bundle、在 `node_modules` 里建链接。
完了重启 DSH，敲 `/ear`。

---

## 装完之后（所有方式通用）

1. 重启 DSH；
2. 命令行敲 `/ear`，拿到：
   - 手机填的地址：`http://<电脑局域网IP>:8788/ingest`
   - token
3. **Windows 防火墙放行 8788（只专用网络）**：

```powershell
netsh advfirewall firewall add rule name="LuYinDou Ear 8788" dir=in action=allow protocol=TCP localport=8788 profile=private
```

（管理员 PowerShell 里执行一次；不放行手机推不进来。）

4. 录音豆 App 填地址和 token，点「测试推送」；
5. 在 QQ 里问大肥鱼「我今天说了什么」验证。

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File C:\Aurabot\dsh-ear\scripts\uninstall.ps1
```

会从 profile 里移除依赖和 bundle，并删掉 `node_modules\dsh-ear` 链接；数据目录保留，要删自己删。
